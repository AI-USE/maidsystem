# MADOS (Molecular Analysis & Decoding OS)

謎解きイベント・脱出ゲーム向けに設計された、堅牢でモダンなデスクトップOSシミュレーター。

## 🌟 主な機能
- **Dark Minimalism UI**: 洗練された「静かな闇」を表現したデザイン（ガラスモーフィズム採用）。
- **完全キオスクモード**: 子機はシステムショートカットを遮断し、Windows機能を隠蔽。
- **遠隔操作**: 親機から子機へ、強制的なイベント（画面揺れ、フリーズ、ログ送信等）を発火。
- **オンデマンド監視カメラ**: 必要時のみ子機のカメラを起動し、低負荷で親機へ映像を転送。
- **ローカル完結型**: インターネット不要。ローカルネットワークのみで動作。

## 🛠️ 開発・テスト方法（アプリとして実行）

ブラウザではなく、実際のアプリ（Electron）ウィンドウとして起動してテストする方法です。

### 1. 依存関係のインストール
プロジェクトのルートディレクトリで実行してください：
```bash
npm install
```

### 2. 親機 (Master) のアプリ起動
```bash
npm run app:master
```
管理用のデスクトップアプリが起動します。

### 3. 子機 (Child) のアプリ起動
```bash
npm run app:child
```
子機アプリがフルスクリーン（開発時は調整可能）で起動します。

> **注意**: ブラウザで確認したい場合は `npm run dev:master` または `npm run dev:child` を使用してください。

## 📦 ビルド方法 (EXEファイルの生成)

Windows用の実行ファイル（.exe）を生成する手順です。

### 全て一括でビルド
```bash
npm run dist:all
```

### 個別にビルド
- **子機のみ**: `npm run dist:child`
- **親機のみ**: `npm run dist:master`

### 生成物の場所
ビルド完了後、ルートの `dist/` フォルダにポータブルEXEが生成されます。
- `dist/child/MAD-OS-CHILD.exe`
- `dist/master/MAD-OS-MASTER.exe`

> **署名（コードサイニング）について**:
> 本プロジェクトのビルド設定は、**「署名なし」のポータブルEXE**を生成するように構成されています。
> そのため、起動時にWindows SmartScreenの警告（「WindowsによってPCが保護されました」）が表示される場合がありますが、詳細情報をクリックして「実行」を選択することで起動可能です。
> 学内展示や現場での運用を想定した軽量な配布形式です。

## 🔐 重要な操作・パスワード (子機)

子機の制限を解除したり、イベントを発生させたりするためのパスワードです。

| 目的 | パスワード | アクション |
| :--- | :--- | :--- |
| **OS終了** | `MADREST104` | アプリを完全に終了しデスクトップに戻る |
| **イベント発火** | `EVT_TRIGGER_99` | 謎解き用のイベント関数を実行（デバッグログに記録） |
| **管理画面へ** | `ADMIN_DASH` | セットアップ（IP入力）画面を再表示 |

## 📡 ネットワーク仕様
- **Socket.io**: ポート `3030`（コマンド・データ通信用）
- **UDP Discovery**: ポート `3031`（親機の自動検出用）
