# GOV-CORE OS (Desktop Simulator for Escape Room)

謎解きイベント・脱出ゲーム向けに設計された、堅牢でモダンなデスクトップOSシミュレーター。

## 🌟 主な機能
- **GOV-CORE OS Dark Cyber UI**: 深い黒（#050508）と真紅・スレートブルーを基調とし、蛍光ネオンを完全に排した緊迫のサイバーパンク・グラデーション。
- **完全キオスクモード**: 子機はシステムショートカットを遮断し、Windows機能を隠蔽。
- **一斉スタート・進行管理**: 親機からの謎解きスタートボタン一発で、全子機で同時に動画（`public/videos/start/`）が再生され、再生完了後に7分間のタイマーが始動します。
- **BGM待機音・一時停止（Pause）**:
  - 待機中（親機がスタートを押す前）は自動的に ambient BGM（bgm.mp3）がループ放送されます。
  - ゲーム一時停止中、タイマーと画面進行がロックされ、子機からは「**現在ゲーム停止中**」の警告ループが再生されます。
- **新・メイドコントロール（配達システム）**:
  - 物品のある部屋コード、物品コードを入力し配達要請を行います。正しい組み合わせ（`maid_items.json`）を登録しておくことで自動稼働し、Discordボットにもループ音声で配達要請が連動します。
- **オンデマンド監視カメラ**: 必要時のみ子機のカメラを起動し、進行フェーズごとに色分けを施した防犯グリッドから遠隔監視が可能。

## 🛠️ 開発・テスト方法（アプリとして実行）

### 1. 依存関係のインストール
```bash
npm install
```

### 2. 親機 (Master) のアプリ起動
```bash
npm run app:master
```

### 3. 子機 (Child) のアプリ起動
```bash
npm run app:child
```

---

## 📦 ビルド方法 (EXEファイルの生成)

```bash
npm run dist:all
```

## 🔐 重要な操作・パスワード (子機)

| 目的 | デフォルトパスワード | アクション |
| :--- | :--- | :--- |
| **OS終了** | `MADREST104` | アプリを完全に終了しデスクトップに戻る |
| **イベントロック解除** | `EVT_TRIGGER_99` | 謎解き用イベント画面（locked）の解除コード |
| **管理者用イベント解除** | `ADMIN_DASH` | PDF 1 閲覧から管理者セッションへの移行コード |
| **管理者ツール（セットアップ）** | `ADMIN_SETUP` | セットアップ（IP・パスワード入力）画面を強制表示 |
