# 🛡️ MAD-OS ファイヤーウォール設定ガイド

MADOSは親機（Master）と子機（Child）の間で独自のネットワーク通信を行います。正常に動作させるには、Windowsファイヤーウォールの設定が必要です。

## 1. 自動設定（推奨）

付属のPowerShellスクリプトを使用して、必要なポートを一括で開放できます。

### 実行手順:
1. `scripts` フォルダ内の `setup_firewall.ps1` を右クリック。
2. **「PowerShellで実行」** を選択。
3. （重要）管理者権限の許可を求められたら「はい」を選択してください。

---

## 2. 手動設定

手動で設定を行う場合は、以下のルールを「受信規則」および「送信規則」に追加してください。

| 項目 | プロトコル | ポート番号 | 用途 |
| :--- | :--- | :--- | :--- |
| **MADOS Master** | TCP | 3030 | ソケット通信・データ制御 |
| **MADOS Discovery** | UDP | 3031 | 端末の自動検出 |

### 手順:
1. Windowsキーを押し、「Windows Defender ファイアウォール」を検索。
2. 左メニューの **「詳細設定」** をクリック。
3. **「受信規則」** -> **「新しい規則...」** を選択。
4. **「ポート」** を選択し、上記表のプロトコルとポートを入力して「接続を許可する」に設定。
5. 同様の操作を **「送信規則」** でも行います。

---

## 3. ネットワーク診断ツール

通信がうまくいかない原因を特定するためのスクリプトが用意されています。

### 実行手順:
1. `scripts` フォルダ内の `check_network.ps1` を右クリック。
2. **「PowerShellで実行」** を選択。
3. 表示される結果を確認してください（IPアドレスが想定通りか、ポートが待機中かなど）。

---

## 4. トラブルシューティング

### 通信が繋がらない場合:
*   **パブリック/プライベート設定:** ネットワーク設定が「パブリック」になっていると制限が厳しくなります。可能な限り「プライベートネットワーク」に設定してください。
*   **サードパーティ製アンチウイルス:** マカフィーやノートンなどのソフトを入れている場合、Windowsの設定とは別に、そのソフト側で3030/3031ポートを許可する必要があります。
*   **学内・企業内LAN:** ネットワーク機器（ルーター）側でポートが閉じられている場合があります。その場合はモバイルWi-Fiやローカルの無線ルーターを使用してください。
