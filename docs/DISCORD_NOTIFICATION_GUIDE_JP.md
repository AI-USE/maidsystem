# MAD-OS Discord ボット音声通知マニュアル

本マニュアルでは、謎解き公演（エスケープルーム等）の進行状況やプレイヤーのアクションに合わせて、Discordのボイスチャットに自動再生される音声通知（TTS / 音声合成）の仕様・タイミング・日本語再生テキストについて解説します。

---

## 🔊 Discordボット音声通知システムとは？

MAD-OS Master（親機）は、公演進行の特定のタイミングで、接続されたDiscordボットを通じて自動的にボイスチャットに日本語の音声アナウンス（TTS）を直接流し込みます。
管理者は親機の「設定パネル」から **Discordボットトークン (API Key)** と **ボイスチャットチャンネルID** を入力するだけで、シームレスな音声アナウンス演出を行うことができます。

## 🛠️ 導入と検証方法

1. **Discordボットの設定**:
   - [Discord Developer Portal](https://discord.com/developers/applications) にてボットを新規作成。
   - `Bot Token` を取得。
   - ボットに `Guilds` および `GuildVoiceStates` などの権限（Privileged Gateway Intents）を有効化し、公演用サーバーの音声チャンネルにボットを追加（管理者招待リンクから参加）。

2. **Master UIでの接続**:
   - Masterの「設定パネル」を選択。
   - ボットの `Token` および再生対象となる Discord の `ボイスチャンネルID`（チャンネル右クリック「IDをコピー」で取得）をそれぞれ入力。
   - 接続に成功すると、画面上のステータスランプが「**接続中**（緑色）」になります。

3. **テスト再生**:
   - 「設定パネル」の最下部にある「**Discord TTS テスト再生**」をクリックすると、即座に Discord 上のボイスチャンネルでボイスメッセージがテスト配信されます。
