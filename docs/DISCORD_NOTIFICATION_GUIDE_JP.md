# GOV-CORE OS Discord ボット音声通知・TTSマニュアル

本マニュアルでは、謎解き公演（エスケープルーム等）の進行状況やプレイヤーのアクションに合わせて、Discordのボイスチャットに自動再生される音声通知（TTS / 音声合成）の仕様・タイミング・日本語再生テキストについて解説します。

---

## 🔊 Discordボット音声通知システムとは？

GOV-CORE OS Master（親機）は、公演進行の特定のタイミングで、接続されたDiscordボットを通じて自動的にボイスチャットに日本語の音声アナウンス（TTS）を直接流し込みます。
管理者は親機の「設定パネル」から **Discordボットトークン (API Key)** と **ボイスチャットチャンネルID** を入力するだけで、シームレスな音声アナウンス演出を行うことができます。

---

## 📅 音声通知・タイミング一覧（タイミング・テキスト詳細）

自動音声合成（TTS）が配信される全トリガーと再生テキストの一覧は以下の通りです。

| トリガーキー | 発生タイミング（トリガー条件） | 再生される日本語テキスト内容 |
| :--- | :--- | :--- |
| **START** | ・親機で「謎解きスタート」を押して unskippable 動画の再生が終わった時 | 「ゲームスタート。ミッションを開始します。制限時間は7分です。」 |
| **TIMER_6** | ・残り制限時間：6分経過時 | 「残り時間、6分です。」 |
| **TIMER_5** | ・残り制限時間：5分経過時 | 「残り時間、5分です。」 |
| **TIMER_4** | ・残り制限時間：4分経過時 | 「残り時間、4分です。」 |
| **TIMER_3** | ・残り制限時間：3分経過時 | 「残り時間、3分です。」 |
| **TIMER_2** | ・残り制限時間：2分経過時 | 「残り時間、2分です。」 |
| **TIMER_1** | ・残り制限時間：1分経過時 | 「残り時間、1分です。急いで暗号を解読してください。」 |
| **TIMER_10S** | ・制限時間 残り 10 秒 | 「10」 |
| **TIMER_9S~1S** | ・制限時間 残り 9 秒 〜 1 秒 | 各カウントダウン数値（「9」「8」〜「1」） |
| **FINISH** | ・制限時間が終了し、タイムアップ（0秒）になった時 | 「制限時間終了。ゲームオーバーです。システムを強制停止します。」 |
| **STOP** | ・親機で「ストップ / 中断」をクリックした時 | 「解説が終了しました。お疲れ様でした。」 |
| **RETIRE** | ・プレイヤー端末で「リタイア」を押した瞬間<br>※解除されるまで **5秒間隔で自動ループ** します。 | 「警告、警告。{name}がリタイアしました。」<br>*(※ `{name}` はリタイアした端末名に自動置換されます)* |
| **DELIVERY_LOOP**| ・プレイヤー端末のメイドコントロールで正しい物品コードが入力された時<br>※スタッフが解除するまで **8秒間隔で自動ループ** します。 | 「配達要請、部屋〇〇、物品〇〇。」<br>*(※ 正しい組み合わせの部屋・物品名が連呼されます)* |
| **DELIVERY_CLEAR**| ・スタッフが親機の「配備完了」を押した瞬間 | 「物品〇〇、配備完了しました。」 |

## ⏸️ 一時停止（PAUSE）中の挙動

親機から一時停止をトリガーすると、子機側では入力制限とともに子機スピーカーから「**現在ゲーム停止中**」の音声が5秒間隔で無限ループ再生されます。
これにより、現場のプレイヤーに対してゲームが中断していることを明確に周知することができます。
