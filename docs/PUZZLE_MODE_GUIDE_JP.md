# GOV-CORE OS なぞ解きモード（PUZZLE MODE）運用・仕様マニュアル

本ドキュメントでは、MAD-OSからリブランドされた「GOV-CORE OS」における、ミステリーイベント・脱出ゲームに特化した「なぞ解きモード」のフェーズ推移、親機・子機間の同期仕様、および操作手順について解説します。

---

## 1. 概要とコンセプト

「なぞ解きモード」は、脱出ゲームや公演イベントのクライマックス、あるいは緊急ミッションの発生を緊迫したビジュアルとインタラクティブなUIで演出するための特別演出用システムです。
MADOSの標準仕様から「ダークサイバー」なビジュアルへと一新され、蛍光色（ネオンカラー）を排除した深みのある暗色系（ブラック `#050508` を基調とし、鮮やかなダーククリムゾン、スレートブルーのオーラグラデーション）による高いセキュリティシステム感を持つ演出となっております。

---

## 2. なぞ解きモードのフェーズ遷移（ステートマシン）

なぞ解きモードが開始されると、子機は以下の **5つのフェーズ** を経て進行します。

```
 [通常モード (idle)] -- (親機から PUZZLE_START)
        |
        v
 1. 制限画面フェーズ (locked) ---- [イベントパスワード入力] ----> 2. PDF閲覧フェーズ 1 (browsing_pdf_1)
                                                                            |
                                                                  [電源ボタンをクリックして]
                                                                  [イベントパスワードを入力]
                                                                            |
 4. 管理者デスクトップ (admin_desktop) <-- (5秒間の起動演出) -- 3. GOV-CORE OS 起動ロード演出 (boot_loading)
     ├─ ① 防犯カメラシステム (ライブ映像監視・拡大)
     ├─ ② メイドコントロールシステム (稼働トグル、温度調整、ゲート解錠)
     └─ ③ 処刑停止用パスワード入力 (カウントダウンタイマーの停止)
```

---

## 3. 各フェーズの詳細仕様

### 【通常モード (idle)】
- 通常のMAD-OSまたはGOV-CORE OSの待機画面です。
- 親機からの遠隔操作や通常プラグインの起動が可能です。

### 【フェーズ 1：制限画面フェーズ (locked)】
- **トリガー**: 親機から「謎解きスタート（`PUZZLE_START`）」または「再起動（`PUZZLE_RESTART`）」の指令を受信。
- **時計・タイマーの上書き**:
  - 子機画面右上の現在時刻が**その日の23時53分40秒**に強制固定され、その時刻から通常通り時を刻み始めます。
  - 右側に**「処刑まで残り 7分00秒（420秒）」**のカウントダウンタイマーが作動し、リアルタイムで減少します。
- **画面制限**: 全画面が「SYSTEM_RESTRICTED（システム制限画面）」で覆われ、キーボードやマウスによる通常操作やデスクトップへのアクセス、Dockのボタンがすべて非表示になります。
- **ロック解除方法**:
  - 画面中央の入力欄に**「イベント用パスワード」**（デフォルト: `EVT_TRIGGER_99`、設定ファイルで任意に変更可能）を入力して「ロック解除システム起動」を実行すると、フェーズ 2 へ移行します。

### 【フェーズ 2：PDF閲覧フェーズ 1 (browsing_pdf_1)】
- **画面仕様**: 標準のデスクトップアイコンや通常アプリの起動は一切隠蔽されます。
- **PDF閲覧**: 画面左側に「処刑装置起動手順_LOG_832.pdf」と題された極秘データのモックアップがスクロール可能な状態で表示されます。プレイヤーはここから次の謎解きの手がかり（管理者モードへのアクセス手順）を読み解きます。
- **制限フッター**: 下部のDockには、**「パスワード保護された電源（システム終了）ボタン」**のみが表示されます。他のアイコンは表示されません。
- **移行方法**:
  - 電源ボタンをクリックすると管理者認証プロンプトが開きます。
  - プロンプトに**「イベント用パスワード」**（デフォルト: `EVT_TRIGGER_99`）を入力して「システム起動」を押すと、フェーズ 3 へ移行します。

### 【フェーズ 3：GOV-CORE OS 起動ロード演出 (boot_loading)】
- **演出効果**: 音響演出やシステムブートを想定した、高精細な「GOV-CORE OS v5.0」のカーネル読み込みシネマティックアニメーションが全画面に **5秒間** 流れます。
- **移行方法**: 5秒経過後、自動的にフェーズ 4 へ移行します。

### 【フェーズ 4：管理者デスクトップ (admin_desktop)】
- **デスクトップ構成**: 高度管理者用のセキュアデスクトップです。
- **PDF閲覧 2**: デフォルト状態では「管理者限定極秘データ_SEC_992.pdf」が表示されており、エントランスのロック解除や処刑プログラムのオーバーライド手順を閲覧できます。
- **3大管理者用ソフトウェア**: デスクトップ右側に3つの大きなアプリケーション起動ボタンが並び、クリックすることでそれぞれのモックモジュールに切り替わります（同時に起動できるのは1つのみ）。
  1. **防犯カメラシステム (SECURITY_CAM_MONITOR)**
     - 施設内のカメラグリッドを模した 2x2（4画角）の監視映像を表示。
     - 各フィードをクリックすることで、ノイズやスキャンラインの効いた高画質な全画面ライブモニタリングに拡大表示されます。
  2. **メイドコントロールシステム (MAID_CONTROLLER)**
     - メイドの稼働トグル（ACTIVE / 緊急停止）、隔壁エリアの目標温度設定（0.5°C刻みで調整可能）、エントランスゲートのロック解錠（LOCKED / UNLOCKED）を行えるコントロールパネル。
  3. **処刑停止用パスワード入力 (EXECUTION_OVERRIDE)**
     - カウントダウンタイマーを強制停止させるための認証フォーム。
     - **「イベント用パスワード」**（デフォルト: `EVT_TRIGGER_99`）を入力し「処刑停止指令を実行」を押すと、タイマーが完全に安全停止し、ステータスが **「システム安全 (SYSTEM_SECURE_OVERRIDE)」** に変わり、右上のカウントダウンが安全な緑色の表示（残り0分00秒）に固定されます。

---

## 4. 親機（コントロールパネル）側の操作

管理者は、親機の **「Performance Panel（パフォーマンスパネル）」** タブから一括で制御を行います。

- **「なぞ解きスタート (START)」**:
  - 接続されているすべての子機（または選択された子機）に対して `PUZZLE_START` 指令を送り、一斉に強制ロック、時計23:53:40への同期、7分間のカウントダウンを開始させます。
- **「なぞ解き中断 (STOP)」**:
  - `PUZZLE_STOP` 指令を送り、なぞ解きモードを直ちに中断させ、通常待機画面（idle）に戻します。タイマーや上書きクロックはリセットされます。
- **「なぞ解き再スタート (RESTART)」**:
  - `PUZZLE_RESTART` 指令を送り、現在の進行状況を無視して最初の「制限画面（locked / 7分タイマー / 23:53:40）」にリセットして開始させます。

## 5. 運用上のパスワード・設定カスタマイズ

子機のパスワード情報は `apps/child/src/App.tsx` または `mados_config.json`（設定ファイル）の優先順位に則って管理されます。

- **デフォルト イベント用パスワード**: `EVT_TRIGGER_99`
  - 制限画面の突破、管理者モード移行プロンプト、処刑完全停止フォームのすべての認証で使用される共通コードです。
  - 変更する場合は、子機の初期セットアップ画面（Setup Wizard）、または管理GUI（Admin Dashboard）から「イベント用パスワード (MADOS_PASS_EVENT)」を編集してください。変更値は自動でローカルストレージおよび config ファイルに保存され、環境変数よりも優先して適用されます。
- **デフォルト システム終了パスワード**: `MADREST104`
  - なぞ解きモード時以外の通常デスクトップ終了時、またはセットアップウィザードに戻る際に使用します。
