# GOV-CORE OS なぞ解きモード（PUZZLE MODE）運用・仕様マニュアル（完全版）

本ドキュメントでは、GOV-CORE OS における、ミステリーイベント・脱出ゲームに特化した「なぞ解きモード」のフェーズ推移、高信頼性オフラインバックアップ機能、親機・子機間の同期仕様、および詳細な設定方法について解説します。

---

## 1. 概要とコンセプト

「なぞ解きモード」は、脱出ゲームや公演イベントのクライマックス、あるいは緊急ミッションの発生を緊迫したビジュアルとインタラクティブなUIで演出するための特別演出用システムです。
ブラック `#050508` を基調とし、鮮やかなダーククリムゾン、スレートブルーのオーラグラデーションによる高いセキュリティシステム感を持つ演出となっております。

---

## 2. なぞ解きモードのフェーズ遷移（ステートマシン）

なぞ解きモードが開始されると、子機は以下の **5つのフェーズ** を経て進行します。

```
 [通常モード (idle) / スタート待機中 (BGMループ再生)] -- (親機から一斉スタート / またはオフライン時間予約スタート)
        |
        v
 1. 強制全画面スタートビデオ配信 (videoPlaying / *ビデオ再生完了まで完全ロック*)
                                                    |
                                                    v
 2. 制限画面フェーズ (locked) ---- [① イベントパスワード入力] ----> 3. PDF閲覧フェーズ 1 (browsing_pdf_1)
                                                                            |
                                                                  [フローティング電源ボタンをクリックして]
                                                                  [② 管理者用イベント解除パスワードを入力]
                                                                            |
 5. 管理者デスクトップ (admin_desktop) <-- (5秒間の起動演出) -- 4. GOV-CORE OS 起動ロード演出 (boot_loading)
     ├─ [開始3秒後: 全画面強制配信ビデオ (再生完了まで完全ロック)]
     ├─ ③ 特大極秘データ PDF 2 閲覧 (表示/非表示トグル付き、再表示可能、iframe実ファイル表示)
     ├─ ④ 全画面防犯カメラシステム (CAM_01 / CAM_02 択一表示、ビデオコントロール操作)
     ├─ ⑤ 全画面メイド配達コントロールシステム
     │   ├─ オンライン時: 親機への要請通知 + Discord Bot TTSループ
     │   └─ オフライン時: 自機スピーカー音量MAXで10秒間自動音声ループ -> 自動で配備完了(クリア)
     ├─ ⑥ 全画面処刑停止用パスワード入力 (残り20秒以下限定、申請送信後は一発ロック、暗転ブラックアウト待機)
     └─ [電源ボタン押下時]: 「これは謎には関係ありません」とシステム警告ダイアログを表示
```

## 3. 各フェーズの詳細仕様

### 【通常モード (idle) / スタート待機中】
- 通常のGOV-CORE OSの待機画面です。
- 親機からの一斉スタート（`PUZZLE_START`）を待機している間、** ambient BGM (bgm.mp3) がバックグラウンドでループ再生 **され、緊迫感を高めます。
- **BGM音量設定**: 子機の初回インストール時の管理設定画面（Setup）で、音量スライダー（0%〜100%）によって個別に調整可能です。
- **ヘッドホン出力**: 音声（BGMおよびSE）は、演出上、原則としてヘッドホンに優先的に出力されるよう構成されています。

### 【フェーズ 1：強制全画面スタートビデオ配信 (videoPlaying)】
- **トリガー**: 親機から「謎解きスタート（`PUZZLE_START`）」または「一斉再起動（`PUZZLE_RESTART`）」の指令を受信した瞬間に、子機全員で同時にスタート。
- **演出効果**: 全画面に「緊急強制システム介入配信」ビデオが再生されます。
- **時間基準から再生完了（onEnded）基準への移行**:
  - 本バージョンより、一律の12秒などの「タイマー指定による自動終了」を完全に廃止し、**「動画が最後まで再生し終わったイベント（onEnded）」を基準**にして自動的にフェーズ 2（制限画面フェーズ）へ遷移します。
  - これにより、動画の尺を変更した場合でも、プログラムを改変することなく映像と演出のタイミングが完璧に同期します。
- **操作ロック**: 再生中は入力を受け付けず、画面を閉じることはできません。
- **時限開始**: ビデオ配信が100%完了した瞬間に、自動的にフェーズ 2（制限画面フェーズ）へ遷移し、**ここから初めて7分カウントダウンタイマーが動き出します**。

### 【フェーズ 2：制限画面フェーズ (locked)】
- **時計・日付・タイマーの上書き**:
  - 子機画面右上の現在日付と時刻が、その日の日付および**23時53分40秒**に強制固定され、そこから刻み始めます。
  - 右側に**「処刑まで残り 7分00秒（420秒）」**のカウントダウンタイマーが始動し、リアルタイムで減少します。
- **画面制限**: 全画面が「SYSTEM_RESTRICTED（システム制限画面）」で覆われ、デスクトップへのアクセス、Dock of ボタンがすべて非表示になります。
- **ロック解除方法**:
  - 画面中央 of 入力欄に**「イベント用パスワード」**（デフォルト: `EVT_TRIGGER_99`、設定ファイルで任意に変更可能）を入力して「ロック解除システム起動」を実行すると、フェーズ 3 へ移行します。

### 【フェーズ 3：PDF閲覧フェーズ 1 (browsing_pdf_1)】
- **画面仕様**: 標準のデスクトップアイコンや通常アプリの起動は一切隠蔽されます。
- **完全フルスクリーン表示**:
  - PDFファイル（`public/documents/doc1.pdf`）が `iframe` 要素によって**画面全体（全面いっぱいに）100%統合表示**され、スクロール以外のボタン、 statusbar や Dock は非表示となって閉じることができません。
- **管理者セッション移行方法**:
  - 画面右上にある極小のフローティング電源ボタンをクリックすると、管理者認証プロンプトが開きます。また、物理的なキープレス（`Escape`、`A` または `a`）でも同じプロンプトを開くことができます。
  - プロンプトに**「管理者用イベント解除パスワード」**（デフォルト: `ADMIN_DASH`）を入力して「システム起動」を押すと、フェーズ 4 へ移行します。

### 【フェーズ 4：GOV-CORE OS 起動ロード演出 (boot_loading)】
- **演出効果**: 「GOV-CORE OS v5.0」のカーネル読み込みシネマティックアニメーションが全画面に **5秒間** 流れます。
- **移行方法**: 5秒経過後、自動的にフェーズ 5 へ移行します。

### 【フェーズ 5：管理者デスクトップ (admin_desktop)】
- **デスクトップ構成**: 高度管理者用のセキュアデスクトップです。
- **3秒後の強制フルスクリーンビデオ**:
  - 管理者デスクトップ起動から**3秒後**、システムが自動的に全画面「緊急強制システム介入配信」画面に遷移します。こちらも**映像ファイルの再生完了（onEnded）を検知**した瞬間に自動的にフェーズ 5 の操作可能デスクトップへと戻ります。
- **電源ボタン押下時仕様**:
  - Dock内の一時終了ボタンや電源ボタンを押した際、「**これは謎には関係ありません**」というシステム警告ダイアログを表示し、演出の没入感を守ります。
- **メイド配達コントロールシステム (MAID_CONTROLLER)**:
  - 物品がある「**部屋コード**」と「**物品コード**」を入力する欄のみで構成される専用パネル。
  - 正しくない組み合わせが入力された場合：3秒待機した後にエラーメッセージ「**指定された部屋に指定されたものが見つかりませんでした**」が表示され、再入力が可能になるまで**5秒間のインターバルロック（入力制限）**が発生します。

## 4. 高信頼性オフラインバックアップ機能

万が一、公演中や開始前にネットワーク障害やサーバーエラーが発生した場合でも、公演を遅滞なく進行できるよう、以下の **二つのオフラインパターン** を完全に自動化しています。

### パターン 1：公演中に通信が切断された場合
- **シームレスな継続（サイレントモード）**:
  - プレイ中にネットワークが切断されても、画面上にはエラーや警告などの演出を壊す情報を一切出さず、ゲームはそのままローカルで完全に継続されます。その間、裏側で親機への再接続を静行試行し続けます。
- **親機側でのエラー警告表示**:
  - 公演が開始状態（`puzzleTimer !== null`）であるとき、接続が途切れた端末が存在する場合、親機管理コンソール（端末ステータス欄など）に「**[端末名] 通信エラー (CONNECTION ERROR)**」という赤点滅の強烈な警告バナーが表示され、オペレーターに瞬時に知らせます。
- **オフライン時の自動結果・解説動画一斉オートフロー**:
  - 7分間のタイマーが満了（0分00秒）に達すると、子機は自動的に **5秒間の暗転ブラックアウト** に突入します。
  - **自動結果映像再生**: 暗転開始から **3秒経過した時点** で、子機は自身の最終送信コードの判定結果（`correct`/`close`/`failed`、未送信時は自動的に `failed`）に基づき、対応する結果動画（`/videos/result/correct/`、`close/`、または `failed/` の中の動画）を自動的に全画面で再生します。
  - **自動解説映像再生**: 結果動画の再生が100%完了（`onEnded`）した瞬間、親機からの配信コマンドを待つことなく、**自動的にすぐ解説動画（`/videos/commentary/commentary.mp4`）が続けて上映**されます。
  - **自動最終画面ロック**: 解説動画が100%再生完了（`onEnded`）すると、自動的に最終結果リロック画面（`MISSION SUCCESSFUL` または `MISSION FAILED`）にダイレクト遷移し、完全ロックされます。
- **オフライン専用「メイド配達自動TTS呼出・自動完了」機能**:
  - 通常は親機とDiscord Botを通じて配達要請がループ配信されますが、オフライン中（接続切れ、または予約オフライン中）に正しい部屋・物品コードが照合されると、以下のスタンドアロン処理が走ります：
    1. 演奏中のバックグラウンドBGMが一時的に一時停止（またはミュート）されます。
    2. パソコン（子機）のスピーカーに自動切り替えされ、**合成音声の音量が強制的に最大（MAX 1.0）**になります。
    3. 「**[端末名]、[商品名]、運んでください**」という日本語TTSアナウンスが **10秒間、繰り返しループ再生**（約2.5秒間隔で連呼）されます。
    4. 10秒が経過するとループは自動停止し、自動的に「配備完了（要請クリア）」状態になり、BGMが再開されて「配達中」状態のままゲームに支障をきたさず進行できます。

### パターン 2：最初からオフラインで開催する場合
ネットワークインフラを全く使わないスタンドアロン公演用の特別予約開始モードです。

- **開始手順**:
  1. 子機の初回起動時、または「管理者ツール（設定パスワード `ADMIN_SETUP` または終了パスワード入力）」から「Setup」画面を開きます。
  2.  identificator設定の一番下に「**【万が一用】オフライン開催予約**」エリアが配置されています。
  3. 「開始時刻（時・分・秒）」をプルダウンで秒単位まで指定し、「**オフラインで開催（時間予約）**」ボタンを押します。
  4. ボタンを押すと、子機は即座に親機への接続処理を遮断（Socket.ioパラメータを `null` 化）し、フルスクリーンの「**OFFLINE_STANDBY（オフライン開催待機画面）**」へ移行します。
- **待機画面の動作**:
  - 待機画面には設定した「開始予定時刻」が赤字で目立つように表示され、ローカルの時刻が指定時刻に達するまで待機します。
- **自動ゲームスタート**:
  - 指定された時刻（日本標準時）に秒単位で合致した瞬間に、自動的に `PUZZLE_START` コマンドを受けたのと同様にゲームが自動スタート（スタート動画再生 12秒 -> 7分タイマー始動）し、以降はパターン1と同様に完全オフライン仕様として快適に進行します。
- **予約の自動取り消し（キャンセル）仕様**:
  - オフライン待機画面の中央下に「電源ボタン」が配置されています。
  - この電源ボタンをクリックして管理パネルを開き、「管理者用イベント解除パスワード（`ADMIN_DASH`）」を入力すると、設定したオフライン開催予約が **自動的に取り消され（予約クリア）**、設定用Setup画面に綺麗に戻ることができます。

## 5. 必須メディア・アセットファイルと設定方法

すべてのメディア、PDFドキュメント、および音源は、子機の `apps/child/public/` ディレクトリ配下に配置します。
Viteビルド時に自動的に `dist/` ディレクトリにコピーされ、Electron Builderパッケージへ封入されます。

### 動画ファイルが配置されていない場合の「セーフティ（フォールバック）機能」
万が一、テスト中やアセットをまだ配置していない場合でも、プログラムが止まるのを防ぐため、**「映像アセットが見つからない場合は、自動的にデジタルインターフェースのサイバーシミュレーションタイマー（10秒）に切り替える」自動エラーハンドリング機能**が実装されています。
これにより、「アセットなしでも動作検証が可能であり、アセットを配置すると自動的にそちらの映像が優先して再生され、映像の秒数通りに終わる」という高い堅牢性を実現しています。
