# GOV-CORE OS なぞ解きモード（PUZZLE MODE）運用・仕様マニュアル

本ドキュメントでは、GOV-CORE OS における、ミステリーイベント・脱出ゲームに特化した「なぞ解きモード」のフェーズ推移、親機・子機間の同期仕様、および操作手順について解説します。

---

## 1. 概要とコンセプト

「なぞ解きモード」は、脱出ゲームや公演イベントのクライマックス、あるいは緊急ミッションの発生を緊迫したビジュアルとインタラクティブなUIで演出するための特別演出用システムです。
ブラック `#050508` を基調とし、鮮やかなダーククリムゾン、スレートブルーのオーラグラデーションによる高いセキュリティシステム感を持つ演出となっております。

---

## 2. なぞ解きモードのフェーズ遷移（ステートマシン）

なぞ解きモードが開始されると、子機は以下の **5つのフェーズ** を経て進行します。

```
 [通常モード (idle) / スタート待機中 (BGMループ再生)] -- (親機から一斉スタート PUZZLE_START)
        |
        v
 1. 強制全画面スタートビデオ配信 (videoPlaying / 12秒間) -- (ビデオ再生完了後、タイマー始動)
                                                    |
                                                    v
 2. 制限画面フェーズ (locked) ---- [① イベントパスワード入力] ----> 3. PDF閲覧フェーズ 1 (browsing_pdf_1)
                                                                            |
                                                                  [フローティング電源ボタンをクリックして]
                                                                  [② 管理者用イベント解除パスワードを入力]
                                                                            |
 5. 管理者デスクトップ (admin_desktop) <-- (5秒間の起動演出) -- 4. GOV-CORE OS 起動ロード演出 (boot_loading)
     ├─ [開始3秒後: 全画面強制配信ビデオ (12秒間・完全操作ロック)]
     ├─ ③ 特大極秘データ PDF 2 閲覧 (表示/非表示トグル付き、再表示可能、iframe実ファイル表示)
     ├─ ④ 全画面防犯カメラシステム (CAM_01 / CAM_02 択一表示、ビデオコントロール操作)
     ├─ ⑤ 全画面メイド配達コントロールシステム (物品・部屋コード入力、配達要請、配備完了での解除ロック)
     ├─ ⑥ 全画面処刑停止用パスワード入力 (残り20秒以下限定、申請送信後は一発ロック、暗転ブラックアウト待機)
     └─ [電源ボタン押下時]: 「これは謎には関係ありません」とシステム警告ダイアログを表示
```

---

## 3. 各フェーズの詳細仕様

### 【通常モード (idle) / スタート待機中】
- 通常のGOV-CORE OSの待機画面です。
- 親機からの一斉スタート（`PUZZLE_START`）を待機している間、** ambient BGM (bgm.mp3) がバックグラウンドでループ再生 **され、緊迫感を高めます。

### 【フェーズ 1：強制全画面スタートビデオ配信 (videoPlaying)】
- **トリガー**: 親機から「謎解きスタート（`PUZZLE_START`）」または「一斉再起動（`PUZZLE_RESTART`）」の指令を受信した瞬間に、子機全員で同時にスタート。
- **演出効果**: 全画面に「緊急強制システム介入配信」ビデオ（格納先：`apps/child/public/videos/start/`）が自動的に再生されます（12秒間）。
- **操作ロック**: 再生中は入力を受け付けず、画面を閉じることはできません。
- **時限開始**: ビデオ配信が100%まで完了した瞬間に、自動的にフェーズ 2（制限画面フェーズ）へ遷移し、**ここから初めて7分カウントダウンタイマーが動き出します**。

### 【フェーズ 2：制限画面フェーズ (locked)】
- **時計・日付・タイマーの上書き**:
  - 子機画面右上の現在日付と時刻が、その日の日付および**23時53分40秒**に強制固定され、そこから刻み始めます。
  - 右側に**「処刑まで残り 7分00秒（420秒）」**のカウントダウンタイマーが始動し、リアルタイムで減少します。
- **画面制限**: 全画面が「SYSTEM_RESTRICTED（システム制限画面）」で覆われ、デスクトップへのアクセス、Dockのボタンがすべて非表示になります。
- **ロック解除方法**:
  - 画面中央の入力欄に**「イベント用パスワード」**（デフォルト: `EVT_TRIGGER_99`、設定ファイルで任意に変更可能）を入力して「ロック解除システム起動」を実行すると、フェーズ 3 へ移行します。

### 【フェーズ 3：PDF閲覧フェーズ 1 (browsing_pdf_1)】
- **画面仕様**: 標準のデスクトップアイコンや通常アプリの起動は一切隠蔽されます。
- **完全フルスクリーン表示**:
  - PDFファイル（`public/documents/doc1.pdf`）が `iframe` 要素によって**画面全体（全面いっぱいに）100%統合表示**され、スクロール以外のボタン、 statusbar や Dock は非表示となって閉じることができません。
- **管理者セッション移行方法**:
  - 画面右上にある極小のフローティング電源ボタンをクリックすると、管理者認証プロンプトが開きます。
  - プロンプトに**「管理者用イベント解除パスワード」**（デフォルト: `ADMIN_DASH`）を入力して「システム起動」を押すと、フェーズ 4 へ移行します。

### 【フェーズ 4：GOV-CORE OS 起動ロード演出 (boot_loading)】
- **演出効果**: 「GOV-CORE OS v5.0」のカーネル読み込みシネマティックアニメーションが全画面に **5秒間** 流れます。
- **移行方法**: 5秒経過後、自動的にフェーズ 5 へ移行します。

### 【フェーズ 5：管理者デスクトップ (admin_desktop)】
- **デスクトップ構成**: 高度管理者用のセキュアデスクトップです。
- **3秒後の強制フルスクリーンビデオ**:
  - 管理者デスクトップ起動から**3秒後**、システムが自動的に全画面「緊急強制システム介入配信」画面に遷移します（12秒間・操作ロック。格納先：`apps/child/public/videos/admin/`）。
- **電源ボタン押下時仕様**:
  - Dock内の一時終了ボタンや電源ボタンを押した際、「**これは謎には関係ありません**」というシステム警告ダイアログを表示し、演出の没入感を守ります。
- **メイド配達コントロールシステム (MAID_CONTROLLER)**:
  - 物品がある「**部屋コード**」と「**物品コード**」を入力する欄のみで構成される専用パネル。
  - **仕様ルール**:
    1. 事前に `apps/child/src/plugins/maid_items.json` に正しい組み合わせ（例: `RM101` と `ITEM01` など）を登録しておきます。
    2. プレイヤーが入力し「配達を要請」をクリックすると、3秒間の「データ照合中」ローディング状態に入ります。
    3. 正しい組み合わせが入力された場合：
       - 状態は「**配達中**」となり、親機（管理端末）へソケット通知を即座に送信します。
       - 同時に、Discordボットを通じてボイスチャンネルに「**配達要請、部屋〇〇、物品〇〇。**」という合成音声TTSアナウンスを、**スタッフが解除するまで8秒間隔で自動的にループ放送**します。
       - スタッフが親機から「配備完了（要請をクリア）」ボタンを押すと、その物品は公演のなかでは存在しないものとして、子機側でも配達クリア記録（`deliveredItemCodes`）に保存されます。
       - 一度解除された物品コードは、以降再入力しても「**その物品は公演のなかでは存在しません**」と即時エラーになります。
    4. 正しくない組み合わせが入力された場合：
       - 3秒待機した後にエラーメッセージ「**存在しません**」が表示され、再入力が可能になるまで**5秒間のインターバルロック（入力制限）**が発生します。

---

## 4. システム一時停止（PAUSE）と再開（RESUME）

親機から「一時停止 (Pause)」を押すと：
- カウントダウンタイマー、時計、操作の進行がすべて完全にストップします。
- 子機は全体がシステム一時停止用のダークサイバー警告オーバーレイで覆われ、操作がロックされます。
- 同時に、子機スピーカーから「**現在ゲーム停止中**」という合成音声アナウンスが**5秒間隔で無限ループ再生**されます。
- 親機から「再開 (Resume)」を押すと、直ちにタイマーが再始動し、ループアナウンスが消去され、ゲームが復帰します。
